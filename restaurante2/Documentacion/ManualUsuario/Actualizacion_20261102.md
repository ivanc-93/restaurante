# Actualización de presentación — 2 de noviembre de 2026

Las mesas muestran un símbolo, estado completo y acción contextual en tarjetas más compactas. El color se acompaña de texto: Disponible, Ocupada, En limpieza y Reservada. En ventanas pequeñas usa el desplazamiento vertical para ver las demás mesas.

No cambió la operación: abrir la ventana no crea consumo; el primer producto abre el pedido. Cobrar abre revisión de receptor y pago. Una incidencia no equivale a un pago ni a borrar consumo. Se conservan GTQ/Q y comprobantes académicos.

El primer administrador se prepara solo en una base pendiente, con Windows autorizado o token válido. La preparación comprueba respaldo y restauración aislada. No faltan usuarios por haber movido carpetas: una base existente conserva sus cuentas y requiere acceso o recuperación.

La conexión y las credenciales habituales no se modificaron durante esta reorganización. El manual anterior y sus Word/PDF no se sustituyen; esta nota es un complemento. Para la explicación técnica consulta [la guía del código](../EstructuraCodigo/GuiaExposicion.md).
